# Reading List

Небольшой консольный список книг для практики 7.1 по автоматизации код-ревью. Можно добавить книгу, посмотреть список и отметить книгу как прочитанную. Данные сохраняются в локальной SQLite. Нужен Python 3.11 или новее. Все зависимости входят в стандартную библиотеку.

## Запуск

Из корня проекта:

```sh
python3 -m reading_list add "Солярис" --author "Станислав Лем"
python3 -m reading_list add "Пикник на обочине"
python3 -m reading_list read 1
python3 -m reading_list list
python3 -m unittest discover -s tests -v
```

В примере команда `read 1` отмечает первую книгу в новой базе. Узнать ID можно через `list`. По умолчанию данные лежат в файле `.reading-list.sqlite3`. Чтобы использовать отдельную базу, передайте `--db` перед командой.

```sh
python3 -m reading_list --db demo.sqlite3 list
```

## Первый учебный PR

Создай на GitHub пустой репозиторий `reading-list` и привяжи его к локальному. В командах замени `YOUR_LOGIN` на свой логин.

```sh
git remote add origin https://github.com/YOUR_LOGIN/reading-list.git
git push -u origin main
git switch -c feature/unread-filter
```

Реализуй первый сценарий из списка ниже, запусти тесты, сделай коммит и выполни `git push -u origin feature/unread-filter`. Открой PR из этой ветки в `main`. Для практики 7.1 используй открытие PR и комментарий `/make_ai_review` для проверки двух способов запуска ревью.

## Задачи для отдельных PR

1. **Фильтр списка.** Добавь `list --unread`. В режиме фильтра должны отображаться только непрочитанные книги. В тесте подготовь книгу каждого статуса.
2. **Удаление книги.** Добавь `remove ID` с понятной ошибкой для отсутствующего ID. Проверь, что удаляется выбранная книга и соседние записи сохраняются.
3. **Статистика чтения.** Добавь команду `stats`, которая выводит общее количество книг и число прочитанных. Проверь пустой список и список с книгами обоих статусов.
